SWAGATAM - VEGETARIAN RESTAURANT WEBSITE

Files:
- index.html   : Home page
- menu.html    : Vegetarian menu page
- gallery.html : Food and restaurant gallery
- style.css    : Shared styling for all three pages

HOW TO RUN:
1. Extract this ZIP file.
2. Keep all four files in the same folder.
3. Double-click index.html, or open it with your browser.
4. Use the navigation links to move between Home, Menu and Gallery.

DESIGN MATCH:
The CSS uses the Milestone 1 colour palette:
- Primary: #8B3A2B
- Secondary: #D4A373
- Background: #FFF8F0
- Text: #2B2118

The pages include a shared navigation bar, responsive layout, sample vegetarian menu items, food imagery, and footer. Menu prices and the restaurant address/hours are sample project content. Images and Google Fonts are loaded from external URLs, so an internet connection is needed to display them.

This is a frontend prototype using HTML and CSS. It does not yet include a backend server, database connection, or CRUD functionality; those are separate tasks in Milestone 2.
